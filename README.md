# ES Metals · Plantas y Procesos

Presentación web interactiva de la distribución de plantas de ES Metals
(ESM 1, ESM 2 y la planta macro integrada ESM 3) y de los recorridos de
cada línea de negocio.

Sitio publicado con GitHub Pages desde la raíz del repositorio (`index.html`).

- `js/esm1.js`, `js/esm2.js`, `js/esm3.js` — datos de cada planta (áreas, máquinas, elementos).
- `js/data.js` — líneas de negocio y recorridos (`route` escenario actual, `route3` ESM 3).
- `js/render.js` — dibujo de las plantas (SVG, lenguaje de plano).
- `js/flow.js` — capa de flujos (recuadros, numeración, flechas).
- `js/app.js` — interacción.
